# Paddler SHA-256 Hex Context

- `paddler_sha256_hex` is a root Paddler crate, it must not depend on any other Paddler crate
- `paddler_sha256_hex` encodes the SHA-256 digest of bytes as lowercase hexadecimal, so every crate that names something after a digest names it the same way
